# CodeAlpha_ImageGallery

Responsive image gallery built with HTML, CSS & JavaScript — CodeAlpha Frontend Development Internship (Task 1).

## Features
- Grid "contact sheet" layout, responsive across screen sizes
- Category filters (Nature / City / People / All)
- Lightbox view with next/prev navigation (buttons + arrow keys)
- Hover zoom and caption reveal transitions
- Keyboard support: ← → to navigate, Esc to close

## Files
- `index.html` — page structure
- `style.css` — all styling
- `script.js` — filtering + lightbox logic

## How to use
1. Open `index.html` in any browser (no build step needed).
2. Replace the image URLs/captions/categories in `script.js` (the `photos` array) with your own photos.

## Bonus implemented
Category filters (Nature, City, People).
